# 🤝 Personal AI Assistant

An AI-powered Personal Assistant built with **Python**, **Streamlit**, and **n8n** to automate daily tasks through natural language conversations.

The assistant combines an intuitive chat interface with workflow automation to help users manage emails, calendars, notes, tasks, expenses, and more.

---

# ✨ Features

- 💬 AI-powered conversational assistant
- 📅 Calendar and meeting management
- 📧 Email reading, replying, and summarization
- 📝 Smart note taking
- ✅ Task and to-do list management
- 💰 Expense tracking and budgeting
- 🔗 n8n workflow automation
- 🌐 Real-time webhook communication
- ⚡ Fast and responsive Streamlit interface

---

# 🛠 Tech Stack

- Python
- Streamlit
- n8n
- Requests
- uv
- REST APIs
- Webhooks

---



# ⚙️ How It Works

1. The user enters a message in the Streamlit interface.
2. Python sends the request to an n8n webhook.
3. n8n determines the required workflow.
4. The appropriate automation or AI processing is executed.
5. The response is returned to the Streamlit application.
